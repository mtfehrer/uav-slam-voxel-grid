# Folders
- drone-simulation: A drone LiDAR simulation in PyBullet to test 3D occupancy grid mapping of environment with A* pathfinding
- edgeslam-occupancy-grid: Updated EdgeSlam system to extract point cloud and positioning data, importing data into a program to create a 3D occupancy grid, alongside PyVista visualizer
- record+playback-on-jetson: Features to record and playback a rosbag file from a ZED RGBD camera on NVIDIA Jetson
